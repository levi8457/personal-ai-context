# 输出格式

## 默认结构

1. **结论先行**：一句话说明结果或当前状态。
2. **证据**：命令输出、线上 URL、数据条数或日志片段。
3. **下一步**：可执行动作，或需要用户拍板的单选项。

## 排版约定

- 中文正文，代码块标注语言。
- 多项对比用表格；操作步骤用有序列表。
- 单条回复只保留必要信息，避免长篇背景铺垫。

## 验收信息

- 交付页面附线上 URL。
- 改动附验证命令与预期输出。
- 站点更新写明 changelog 条目。

## 避免

- 重复复述已知需求。
- 只给结论不给证据。
- 用开放式提问替代「推荐 + 理由 + 编号选项」。
